# Videokê

Aplicação de videokê offline, inicialmente desenvolvida com HTML, CSS e JavaScript modular.

## Preparar o ambiente

Requer VS Code e Node.js 24.22.2 ou superior na linha 24. Na raiz do projeto, execute:

```sh
npm run setup
```

O setup instala as dependências locais e as extensões recomendadas do VS Code. Para consultar os passos manuais, veja [setup/README.md](setup/README.md).

## Comandos disponíveis

- `npm run lint`: analisa os arquivos JavaScript configurados com ESLint.
- `npm run lint:fix`: aplica correções automáticas oferecidas pelo ESLint.
- `npm run format`: formata os arquivos compatíveis com Prettier.
- `npm run format:check`: verifica a formatação sem alterar arquivos.
